# Historyczny prototyp Supabase

Ten katalog zawiera wcześniejszy prototyp warstwy danych Hotel Marketing Analyzer. Pliki SQL i dawna instrukcja uruchomienia (`README.legacy.md`) nie są używane przez aktualny runtime.

Obecnie Supabase odpowiada wyłącznie za uwierzytelnianie użytkowników, a dane raportowe pochodzą z BigQuery. Katalog pozostaje wyłącznie jako zapis ewolucji projektu; nie należy uruchamiać tych skryptów jako konfiguracji bieżącej aplikacji.
